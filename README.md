# PDF工房

ブラウザだけで動くPDF編集ツールです。ページの並べ替え・削除・回転から、白塗り＋テキストによる書き換え、ペン・マーカー・押印の貼り付けまでを、1枚のWebページで行えます。

**PDFファイルは端末の中だけで処理され、サーバーには一切送信されません。** 成績表や個人情報を含む書類でも、ネットワークに出さずに扱えます。

---

## できること

| 分類 | 内容 |
| --- | --- |
| ページ編集 | 並べ替え（ドラッグ／タッチは長押ししてから移動）、削除、90°回転、複製、白紙の挿入、複数PDFの結合 |
| ページ整理モード | ページの組み替えに画面全部を使う専用画面（パソコン向け）|
| 書き込み | テキスト、ペン、マーカー、四角、直線、白塗り、画像・印鑑の貼り付け |
| 日付印・名前印 | 所属・日付・名前を入れた丸いハンコ（データ印）や、名前だけの丸印をその場で作って押す。色（朱・紺・黒）と大きさを選べます |
| 書体 | ゴシック体・明朝体・UDデジタル教科書体・BIZ UD系などから選択（端末に入っているものが並びます）|
| 文字の書き換え | 白塗りで元の文字を消し、上からテキストを重ねる方式（日本語入力・禁則処理に対応） |
| 書き出し | ファイル名を決めて保存。全ページ、または選択したページだけ（分割にも使えます） |
| 印刷 | 書き込みを含めて、書き出しと同じ内容を印刷。全ページ、または選択したページだけ。横向きのページは横向きの用紙で |
| しおり（目次） | 元のPDFのしおりを引き継ぎます。並べ替えても正しいページを指し、削除したページのしおりは外れます |
| 入力フォーム | 記入欄付きのPDFを、記入できる状態のまま書き出し（ページを複製しても記入欄は独立します）|
| 文字を探す | PDFの中の文字を検索して、該当箇所に色を付けて移動 |
| ページ移動 | ページ番号を入力して移動 |
| 書き込みの手直し | 選ぶとその場に色・太さ・複製・削除が出る |
| 右クリック | ページと書き込みに、それぞれのメニュー |
| その他 | 元に戻す／やり直す、拡大縮小、キーボードショートカット、パスワード付きPDFの読み込み |
| 自動保存 | 編集中の内容を端末内に自動保存。閉じても次に開くときに続きから再開できます |

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `V` `T` `P` `M` `R` `L` `W` `E` | 選択 / テキスト / ペン / マーカー / 四角 / 直線 / 白塗り / 消す |
| `Ctrl`(`⌘`) + `Z` | 元に戻す |
| `Ctrl`(`⌘`) + `Shift` + `Z` | やり直す |
| `Ctrl`(`⌘`) + `S` | PDFを書き出す |
| `Ctrl`(`⌘`) + `P` | 印刷 |
| `Delete` | 選択中の書き込みを削除 |
| `Ctrl`(`⌘`) + ホイール | 拡大・縮小（カーソルの位置を中心に。ページ整理ではサムネイルの大きさ） |
| `Ctrl`(`⌘`) + `+` / `-` / `0` | 拡大 / 縮小 / 幅に合わせる |
| `F` | 文字を探す |
| `Enter` / `Shift`+`Enter` | 次の一致 / 前の一致（検索欄で） |
| `↑` `↓` | ページを選ぶ（ページ一覧を選択中） |
| `Ctrl`(`⌘`) + `↑` `↓` | 選んだページを前後に動かす |
| `?` | 使い方とショートカットを表示 |

## 白塗り（墨消し）について

白塗りツールは、見た目を隠すだけでなく**元の文字データそのものを消します**。

そのため、白塗りを使ったページは書き出し時に画像に変換されます。挙動は次のとおりです。

- 白塗りしたページ … 画像化されるため、**文字の選択・コピー・検索はできなくなります**。隠したはずの文字が後から読まれる心配もありません。
- 白塗りしていないページ … そのまま保たれ、文字の選択・コピー・検索ができます。
- ファイルの大きさ … 白塗りしたページは1ページあたり約100〜400KB増えます（内容によります）。
  白塗りが必要なページだけに使うと、ファイルを小さく保てます。

氏名・住所・成績など、人に見せたくない情報を消す用途では白塗りを使ってください。
四角ツールで白く塗りつぶしただけでは、下の文字は消えずに残ります。

## ページ整理モード（パソコン向け）

画面上の「ページ整理」に切り替えると、ページの組み替えだけに画面全部を使えます。ページ数の多い資料の並べ替えや抜き差しに向いています。

| 操作 | 動き |
| --- | --- |
| クリック | ページを選ぶ（`Shift`で範囲、`Ctrl`(`⌘`)で追加） |
| ドラッグ | 並べ替え |
| ページの上にカーソルを置く | そのページだけの回転・削除 |
| ページの間の `＋` | そこに白紙、または別のPDFファイルを差し込む |
| 右クリック | ページのメニュー |
| ダブルクリック | そのページの書き込み画面に戻る |
| 右上の「大きさ」 | サムネイルの大きさを変える（次回も覚えています） |

上段には、選んだページへの操作（回転・複製・挿入・書き出し・削除）がまとまっています。

スマートフォンでは切り替えは出ません。ページ一覧の引き出しをお使いください。

---

## タブレット・スマートフォンでの操作

画面は縦長の端末に合わせて組み替わります。上段はファイル名とページ位置だけの1行、道具は親指の届く下段、ページ一覧は左からの引き出しです。「開く」「元に戻す」などは右上の「⋯」に入ります。

| 操作 | 動き |
| --- | --- |
| 2本指でなぞる | ページを上下左右に動かす |
| 2本指を広げる／縮める | 拡大・縮小 |
| 1本指（選択ツール） | ページを動かす。書き込みを掴んだときは移動・拡大縮小 |
| 1本指（ペンなどの書き込みツール） | そのまま描く |
| ページ一覧を長押ししてから動かす | ページの並べ替え |
| ページ一覧を長押しせずになぞる | 一覧のスクロール |

書き込みの途中で2本目の指を置いた場合、描きかけの線は取り消され、拡大縮小に切り替わります。

## 自動保存について

編集中の内容（読み込んだPDF・ページの並び・書き込み）は、この端末のブラウザ内に自動で保存されます。
タブを閉じたり、うっかりリロードしても、次に開いたときに「前回の続きがあります」と表示され、そこから再開できます。

- 保存先はブラウザの内部領域（IndexedDB）で、**サーバーには送信されません**。
- 別の端末や別のブラウザには引き継がれません。
- 「新しく始める」を選ぶと、保存されていた内容は消えます。
- 共用のパソコンで個人情報を含む書類を扱ったときは、作業後に **`?` の画面にある「保存された内容を消す」** を押してください（起動時に「新しく始める」を選んでも消えます）。
- 保存が間に合っていないときだけ、タブを閉じる前に確認が出ます。

## GitHub Pages で公開する手順

1. GitHub にログインし、**New repository** から新しいリポジトリを作る（例: `pdf-koubou`）。
   - 公開範囲は **Public**。Private だと GitHub Pages は有料プランが必要です。
2. リポジトリの **Add file → Upload files** を開き、この `README.md` と同じ階層にあるファイル・フォルダを**すべて**ドラッグ＆ドロップする。
   - `index.html` / `sw.js` / `manifest.webmanifest` / `icon.svg` / `icon-192.png` / `icon-512.png` / `.nojekyll` / `vendor` フォルダ
   - `.nojekyll` が画面に出てこない場合は、そのままで構いません（無くても動きます）。
3. **Commit changes** を押す。
4. リポジトリの **Settings → Pages** を開く。
   - **Source** を `Deploy from a branch`
   - **Branch** を `main` / `/ (root)` にして **Save**
5. 1〜3分ほど待つと、同じ画面に公開URLが出ます。

```
https://<GitHubのユーザー名>.github.io/pdf-koubou/
```

このURLを職場の方に共有すれば、そのままブラウザで使えます。インストールは不要です。

### 更新するとき

`index.html` を差し替えて commit すれば、数分で反映されます。反映されないときはブラウザの再読み込み（`Ctrl`+`Shift`+`R`）を試してください。

## オフラインでも使えます

一度開くと内容が端末に保存され、次からはネットワークが無くても動きます（Service Worker）。

スマートフォンやタブレットでは、ブラウザのメニューから「ホーム画面に追加」を選ぶと、アプリのように単独で起動できます。

## サーバーを使わずに配る場合

同梱の **`pdf-koubou-single.html`**（単体版）は、ライブラリまで1ファイルに収めたものです。校内の共有フォルダやUSBメモリに置き、ダブルクリックで開くだけで同じように使えます。GitHub も通信も必要ありません。

※ 単体版は描画処理をメインスレッドで行うため、ページ数の多いPDFでは公開版より少し遅くなります。

### 単体版の作り直し

単体版は `index.html` から生成します。`index.html` を直したら、次を実行して作り直してください（手で両方を直すと、片方だけ古いままになります）。

```
node build-single.js
```

## 自動テスト

`tests/` に、実際のブラウザでアプリを操作して確かめるテスト（Playwright）があります。
GitHub にプッシュするたびに GitHub Actions で自動的に動き、結果はリポジトリの「Actions」タブで見られます。
単体版を作り直し忘れていないかも、ここで確かめます。

主に確かめていること：

- ページの回転・複製・白紙・削除・並べ替え・結合が、書き出したPDFに正しく反映される
- 書き込みが画面と同じ位置に書き出される（回転したページでも文字・画像がまっすぐ）
- 白塗りしたページの文字データが消える
- しおり・入力フォーム・パスワード付きPDFの扱い
- 印刷（用紙の向き、選んだページだけ）、日付印・名前印
- 自動保存からの復元、上の帯が1行に収まること、文字のコントラスト、スマートフォンの画面

手元で動かすときは（Node.js と Python 3 が必要）：

```
npm install
npx playwright install chromium
npm test
```

## 制限事項

- 書き込み（ペン・マーカー・四角・直線）は図形としてPDFに描き込まれるため、拡大してもぼやけません。画像・印鑑は、長い辺が2000pxを超える大きな写真（スマホで撮った写真など）だけ、PDFが大きくなりすぎないよう縮めてから埋め込みます（A4の幅いっぱいに広げても十分な細かさです）。
- 追加したテキストだけは画像になります（日本語フォントを同梱していないため）。そのため、追加テキストの検索・コピーはできません。元のPDFの文字はそのまま検索・コピーできます。
- 書体は、その端末に入っているものから選びます。画像として焼き込むため、書き出したPDFを開く相手に同じ書体が無くても見た目は変わりません。
- 書き出した後に、書き込みだけを編集し直すことはできません。
- 白塗りを使ったページは、文字データを確実に消すためページ全体が画像になります（上の「白塗り（墨消し）について」を参照）。
- 入力フォーム（申請書などの記入欄）は、書き出した後も記入できる状態で残ります。ただし、このアプリの中で記入欄に直接入力することはできません（テキストツールで上から書いてください）。白塗りしたページの記入欄は、ページが画像になるため消えます。
- パスワードで保護されたPDFは、開くときにパスワードを入力すれば扱えます。ただし書き出すときは全ページが画像になります（PDFの暗号を解いたまま中身を組み直せないため）。書き出したファイルにパスワードはかかりません。
- スキャンした画像PDFの文字を検索・選択できるようにする機能（OCR）はありません。
